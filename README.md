# 求職錦囊・智慧履歷互動生成系統 (Interactive Career Resume Builder)

本系統係依據頂級高階求職課程錦囊的核心戰略架構（STAR 經歷模型、量化效益拆解、JD 關鍵字匹配、30 秒電梯簡報）全面改版升級之互動式履歷生成與即時評估終端。協助高階專業人士與主管人才透過結構化問答，迅速提煉最具殺傷力之商業戰績，即時產出符合企業決策層與 HR 偏好之雙欄專業履歷，並支援一鍵匯出標準 Microsoft Word (.docx) 文件與 PDF 列印。

---

## 本次改版重點 (v2.0 全新架構)

1. **全面清空預設值與隱私去識別化**：
   - 徹底移除先前參考履歷中之特定人士姓名、聯絡方式與特定企業經歷。
   - 所有輸入欄位進入時預設均為空白，改以通用高階經理人戰略規範之反灰引導提示文字（placeholder）呈現，提供最高規格之求職隱私保護與泛用性。
2. **頂部增設便捷切換控制項**：
   - **「清空欄位 (空白重設)」**：一鍵清空所有已輸入之欄位與經歷，隨時恢復最乾淨的初始狀態。
   - **「載入通用示範 (高階經理人)」**：內建符合高階營運總監與事業群主管規格之標準 STAR 示範資料，方便隨時切換對照與參考取經。
3. **求職錦囊 STAR 品質評分雷達升級**：
   - 底部即時儀表板視覺化拆解五大維度（基本定位 20%、目標鎖定 15%、摘要說服力 20%、STAR 量化戰績 35%、ATS 關鍵字匹配 10%）。
   - 依據內容即時動態診斷，提供精準之關鍵字補充與數據化強化建議。
4. **完整核心功能無縫運作**：
   - **右側雙欄 A4 即時預覽**：支援高雅商務排版與即時連動，所見即所得。
   - **標準 Word (.docx) 匯出**：採用原生 OpenXML 架構生成標準邊距、層級標題與排版樣式之 Word 文件。
   - **瀏覽器列印 / 存為 PDF**：內建專屬 `@media print` 樣式，自動過濾操作介面，精準適配 A4 規格。
   - **草稿保存與載入 (JSON)**：支援將當前進度匯出為本機 JSON 檔案，或自本機載入續編。

## 核心設計理念與錦囊心法

1. **精準定位與標題對齊 (Target Role & ATS Matching)**：
   - 履歷開頭直接鎖定明確的目標應聘職稱（如：營運副總 / 跨國事業部總經理 / 資深策略營運總監），最大化提升關鍵字匹配率與主管前 6 秒掃描印象。
2. **30 秒電梯簡報摘要 (Professional Summary)**：
   - 透過「年資與核心專長」+「最具殺傷力之量化戰績」+「能為企業創造之即戰力」三道引導題目，自動組合成 150~200 字高說服力開場。
3. **STAR 法則深度拆解 (STAR Experience Breakdown)**：
   - 拒絕流水帳式的職責清單，將每段經歷拆解為：
     - **S (Situation)**：面臨之市場競爭、業務背景或內部瓶頸。
     - **T (Task)**：被指派或主動設定之關鍵目標與 KPI 指標。
     - **A (Action)**：採取的具體戰術、系統導入或跨職能推進。
     - **R (Result)**：最終產出之具體數據（營收增長%、成本節省金額、專案時效倍數）。
   - 支援「一鍵轉化為標準條列成就」功能。
4. **ATS 關鍵字與競爭力矩陣 (Core Competencies & Skills)**：
   - 結構化呈現領域專業專長（Domain Knowledge）、數位系統與分析工具（Tools & Software）、語言能力與專業證照（Certifications）。
