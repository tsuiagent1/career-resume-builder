# 求職錦囊・智慧履歷互動生成系統 (Interactive Career Resume Builder)

本專案係專為**崔董求職轉職與新職涯挑戰**量身打造之互動式履歷生成與評估工具，依據頂級求職課程錦囊的核心實戰架構（STAR 模型、量化戰績挖掘、JD 關鍵字匹配、30 秒電梯簡報）開發，協助使用者透過結構化問答，即時產出符合企業高階主管與 HR 偏好之專業履歷，並支援**一鍵匯出標準 Microsoft Word (.docx) 文件**。

---

## 核心設計理念與錦囊心法

1. **精準定位與標題對齊 (Target Role & ATS Matching)**：
   - 拒絕模糊定位，履歷開頭直接鎖定目標應聘職稱（如：資深營運經理 / 品牌行銷總監），提升 HR 前 6 秒掃描印象。
2. **30 秒電梯簡報摘要 (Professional Summary)**：
   - 透過「專業年資」+「核心專長」+「最具殺傷力之量化戰績」+「即戰力優勢」三道引導題目，自動組合成 150~200 字高說服力開場。
3. **STAR 法則深度拆解 (STAR Experience Breakdown)**：
   - 拋棄傳統平庸的工作職責清單（Job Duties），將每段經歷拆解為：
     - **S (Situation)**：面臨之市場競爭、業務背景或內部瓶頸。
     - **T (Task)**：被指派或主動設定之關鍵目標與 KPI 指標。
     - **A (Action)**：採取的具體戰術、創新方案、工具導入或跨職能推進。
     - **R (Result)**：最終產出之具體數據（營收增長%、成本節省金額、週轉天數、專案規模）。
   - 支援「一鍵轉化為標準條列成就」功能。
4. **ATS 關鍵字與競爭力矩陣 (Core Competencies & Skills)**：
   - 結構化呈現領域專業（Domain Knowledge）、數位系統與分析工具（Tools & Tech）、語言能力與專業證照（Certifications）。
5. **一鍵匯出標準 Word (.docx) 與即時列印**：
   - 內建符合微軟 Word 規範之 OpenXML 生成引擎，自動套用標準邊界、加粗標題、橫線分隔與高雅字型層級，產出即可直接編輯或轉發。
   - 支援離線草稿儲存 (JSON) 與匯入續編。

## 系統檔案結構

- `index.html`：系統完整前端單頁應用程式（包含問答精靈、即時雙欄預覽、履歷評分雷達、Word docx 匯出模組與 JSON 暫存）。
- `README.md`：專案核心架構說明、求職錦囊問答邏輯與使用手冊。
